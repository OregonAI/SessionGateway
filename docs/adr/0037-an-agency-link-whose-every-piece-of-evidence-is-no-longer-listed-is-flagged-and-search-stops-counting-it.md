# An evidence document OLIS no longer lists is flagged, and an Agency Link that rests only on such documents is treated as a node no longer listed is

ADR-0030 flags a row that two complete full pulls in a row have not listed, and ADR-0031 keeps such a row in the lists, flagged, rather than dropping it. Ticket #16 flags a `find_measures` item whose node is no longer listed, and leaves that node out of search's Agency filter (`no-longer-listed-agency-links.test.ts`), but the documents an Agency Link's evidence was read from carry no flag. That matters for two kinds of evidence, a Fiscal Impact Statement and Testimony, whose document is not the node the link sits on (ADR-0027); named-in-text and derived evidence is read from the Version or posting itself. So if OLIS stopped listing SB 69's Fiscal Impact Statement 85414, the Bureau of Labor and Industries' link from it would still tie SB 69's A-Engrossed Version to the Bureau, unflagged, in `find_measures` and in search's Agency filter. The owner decided on 2026-10-31 (PR #45 question 6) on the rule a node already has. Each evidence document no longer listed is flagged where it is named: in `get_measure`'s `agency_links.documents` and in `find_measures`' evidence examples. An Agency Link whose every evidence document is no longer listed is flagged in `get_measure` and `find_measures`, which keep listing it, and search's Agency filter stops counting it, as it leaves out a node no longer listed. A link with any listed evidence document is unchanged.

## Considered Options

- **Flag the documents and keep counting the link everywhere**, search's Agency filter included. Search would then find a Measure through an Agency Link that rests only on documents it leaves out of its own results.
- **Drop a link with no listed evidence from `find_measures` and from search's filter**, showing it only in `get_measure`. A row that stops being listed is not withdrawn (ADR-0031), and `find_measures` would lose an item that `get_measure` still shows.
